# Copiadora XAU

Proyecto web listo para publicar en GitHub y Vercel.

## Incluye
- Página de publicidad
- Botón a WhatsApp
- Formulario de registro
- Diseño responsive

## Uso
1. Sube estos archivos a un repositorio en GitHub.
2. Conecta el repositorio a Vercel.
3. Reemplaza el número de WhatsApp en `script.js`.

## Archivos
- `index.html`
- `styles.css`
- `script.js`
